>

> 看完这份，应该不用猜就知道我们到底要做一个什么东西。

---

## 一、一句话说明

做一个**校园版闲鱼**网页：学生把自己不用的东西挂上去卖，别人搜到、点进去看、模拟下单。
只是课程作业，**不接真实支付，不连数据库，数据存在浏览器本地**。

---

## 二、谁在用（模拟身份）

没有注册登录，假装有两个固定用户：

| 用户 | 编号 | 用来干嘛 |
| --- | --- | --- |
| 我（当前用户） | 101 | 个人中心只看我挂的东西 |
| 别人 | 102 | 演示"买别人的东西" |

---

## 三、五个页面

### 页面 1：商品首页（`/`）

**干嘛的**：像逛集市，所有在卖的东西排成一排卡片，是买家找东西的起点。

**从哪进**：顶部导航点"首页"；发布成功后也可能回到这里；确认完订单可以回这里。

**上面有什么、能干什么**：
- 一个搜索框：输入关键词（比如"教材"），只留下标题里带这个词的商品。
- 一个分类下拉：教材 / 电子产品 / 生活用品 / 运动器材，选一个只看这类。
- 一个排序下拉：默认 / 价格从低到高 / 价格从高到低。
- 三个条件可以**同时用**（比如"教材 + 教材分类 + 从便宜到贵"）。
- 每张卡片显示：分类占位图、标题、成色、价格，点一下进详情。

**干完去哪 / 怎么返回**：点卡片 → 详情页。这是入口页，不用返回。

**特殊情况**：
- 搜不到东西 → 显示"没有找到匹配的商品，换个关键词试试"，不显示空白页。
- 已经卖掉（sold）或下架（offline）的商品 → 不出现在首页，只显示在售的。
- 清空搜索框和筛选 → 恢复显示全部在售商品。

### 页面 2：商品详情（`/product/数字`）

**干嘛的**：看一件东西的完整信息，也是下单的入口。

**从哪进**：首页点任意一张卡片；发布成功后自动跳到新商品的详情页。

**上面有什么、能干什么**：
- 顶部"← 返回首页"链接。
- 显示标题、价格、分类、成色、状态（在售 / 已下架 / 已售出）、商品描述、卖家编号、发布时间。
- 一个"下单"按钮（逻辑由 M5 负责接）。

**干完去哪 / 怎么返回**：点"返回首页"回首页；点下单 → 生成订单，商品变已售。

**特殊情况**：
- 地址里的编号不存在（比如 `/product/9999`）→ 显示"商品不存在"和"回到首页看看其他商品"，不白屏、不报错。
- 商品已被下架或卖出 → 状态标签如实显示，不能下单。

**草图**：

```
┌──────────────────────────────────────┐
│ ← 返回首页                            │
│ ┌──────────┐  ┌──────────────────┐   │
│ │          │  │ 二手高等数学教材     │   │
│ │  教材     │  │ ¥ 25             │   │
│ │ （占位图） │  │ [教材][九成新][在售]  │   │
│ │          │  │ 商品描述：大一用过...│   │
│ │          │  │ 卖家编号：101       │   │
│ │          │  │ [ 下单 ]           │   │
│ └──────────┘  └──────────────────┘   │
└──────────────────────────────────────┘
```

### 页面 3：发布商品（`/publish`）

**干嘛的**：卖家把闲置挂上去。

**从哪进**：顶部导航点"发布"。

**上面有什么、能干什么**：一个表单，填标题、价格、分类、成色、描述，点"发布"提交。

**干完去哪 / 怎么返回**：发布成功 → 自动跳到新商品的详情页；填错了留在原页面，已填内容不清空。

**特殊情况**：
- 标题空白 → 提示"请输入商品名称"。
- 价格空、0、负数或乱填 → 提示"价格必须是大于 0 的数字"。
- 没选分类 → 提示"请选择分类"。
- 保存失败 → 提示"发布失败，请重试。你填写的内容已保留"。

**草图**：

```

│ 成色       [ 九成新            ▾ ]   │
│ 商品描述   [                      ]   │
│           [                      ]   │
│                  [ 发布 ]             │

```

### 页面 4：个人中心（`/profile`）

**干嘛的**：看"我"（编号 101）挂出去的东西，管理自己的商品。

**从哪进**：顶部导航点"个人中心"。

**上面有什么、能干什么**：我发布的商品列表，每件带"下架"和"删除"按钮。

**干完去哪 / 怎么返回**：顶部导航点首页 / 发布 / 订单；下架后回首页就看不到那件了。

**特殊情况**：
- 只显示 `sellerId === 101` 的商品，别人的不显示。
- 没发布过东西 → 显示一句空提示，不显示空白。
- 已经卖掉的商品 → 不能重新上架。
- 不能下架或删除别人的商品（页面上压根不显示别人的）。

**草图**：

```

│ 个人中心                              │

│ ┌──────────────────────────────┐     │
```

### 页面 5：我的订单（`/orders`）

**干嘛的**：看买到的和卖出的订单，卖家在这里确认交易完成。

**从哪进**：顶部导航点"订单"；下单后订单出现在这里。

**上面有什么、能干什么**：订单列表，显示商品名快照、价格快照、状态（待完成 / 已完成）；卖家对"待完成"的订单点"确认完成"。

**干完去哪 / 怎么返回**：顶部导航回首页等页面。

**特殊情况**：
- 不能买自己的商品（卖家编号 = 买家编号）。
- 不能买已售、下架的商品。
- 同一件商品不能重复下单。
- 只有卖家（101）能点"确认完成"，买家不能。
- 刷新页面后订单还在（存在浏览器本地）。

**草图**：

```
┌──────────────────────────────────────┐
│ 我的订单                              │
│ ┌──────────────────────────────┐     │
│ │ 高数教材  ¥25  [待完成]        │     │
│ │ 买家：102  卖家：101           │     │
│ │               [确认完成]       │     │
│ └──────────────────────────────┘     │
│ ┌──────────────────────────────┐     │
│ │ 小台灯  ¥18  [已完成]          │     │
│ └──────────────────────────────┘     │
└──────────────────────────────────────┘
```

## 四、一条完整流程（演示时照这个走）

1. 卖家（101）在**发布页**挂出一件闲置 → 成功跳到详情页。
2. 回到**首页**，能看到刚发布的东西（搜索、筛选、排序都能用）。
3. 点卡片进**详情页**，看信息，点"下单"。
4. 商品变成"已售"，**订单页**多了一条"待完成"订单。
5. 卖家在**订单页**点"确认完成"，状态变"已完成"。
6. 刷新浏览器，东西和订单都还在。

---

## 五、明确不做的（别被问懵）

- 不做真实支付、不接支付接口，页面标明"模拟交易"。
- 不做注册登录、不做权限系统，就两个假用户 101 / 102。
- 不做实时聊天、物流、取消订单、退款。
- 不做服务器和数据库，数据只存当前浏览器，换台电脑不同步。
- 图片目前用占位色块，不找真实图片。
